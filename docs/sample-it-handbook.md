# 星河科技 IT 服务台手册（虚构教学资料）

版本：1.0。以下公司、流程与时限仅用于本项目练习。

## 账号与密码

员工忘记密码时，先在统一身份平台进行自助重置。如果无法通过身份验证，服务台应创建 P2 工单，交由人工核验身份。人工服务台不得通过聊天直接索取员工密码或一次性验证码。

## VPN 连接故障

员工无法连接 VPN 时，应先确认网络连接正常、客户端为最新版本，并记录错误代码。如果错误代码为 VPN-403，应创建 P2 工单并转交网络组；网络组的首次响应目标为 2 小时。不要建议员工关闭终端安全软件。

## 设备报修

笔记本电脑出现硬件故障时，员工提交设备编号、故障现象和联系方式。服务台创建 P3 工单后交给桌面支持组。设备报修的首次响应目标为 1 个工作日。

## 工单升级

影响整个部门登录或网络接入的故障应升级为 P1，并立即通知值班负责人。普通单人问题不得仅因用户催促而自动升级为 P1。
